# @atlas/react

React and Leaflet adapter for Atlas.

Import `leaflet/dist/leaflet.css` in your host application. Import `AtlasMap`, `MarkerLayer`, `ShapeLayer` and `AtlasMapHandle` from `@atlas/react`.

This v0.1 renderer works with **raster tiles**. It does not edit roads, buildings or labels inside a raster tile. A MapLibre vector renderer is planned.
